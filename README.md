# Маршруты Московского метро

Учебный проект на Python: библиотека взвешенного графа и консольная программа,
которая ищет кратчайший маршрут по части Московского метро алгоритмом Дейкстры.

## Возможности

- добавление и удаление вершин и рёбер графа;
- проверка повторных вершин, рёбер и неположительных весов;
- поиск кратчайшего времени через очередь с приоритетом `heapq`;
- восстановление списка станций кратчайшего пути;
- 42 станции трёх линий метро и пять пересадок;
- понятные сообщения об ошибках без трассировки.

Для работы программы нужны только Python 3.11 или новее и стандартная библиотека.

## Запуск

Сначала откройте терминал и перейдите в папку проекта:

```bash
cd /Users/arina/Desktop/metro
```

Команда `path` печатает станции маршрута по одной на строку:

```bash
python3 -m main path \
  --from "Арбатская (Арбатско-Покровская)" \
  --to "Таганская (Кольцевая)"
```

Результат:

```text
Арбатская (Арбатско-Покровская)
Площадь Революции
Курская (Арбатско-Покровская)
Курская (Кольцевая)
Таганская (Кольцевая)
```

Команда `time` печатает только время в минутах:

```bash
python3 -m main time \
  --from "Арбатская (Арбатско-Покровская)" \
  --to "Таганская (Кольцевая)"
```

Для этого примера программа выведет:

```text
10
```

Справка по всем командам:

```bash
python3 -m main --help
python3 -m main path --help
python3 -m main time --help
```

Названия станций нужно вводить точно и заключать в кавычки. Все доступные станции
перечислены в `metro_data.py`.

Если названия совпадают, после станции указана линия, например
`Курская (Кольцевая)` и `Курская (Арбатско-Покровская)`.

## Устройство проекта

- `graph.py` — класс `WeightedGraph` и алгоритм Дейкстры;
- `exceptions.py` — иерархия собственных исключений;
- `metro_data.py` — станции, перегоны, время и пересадки;
- `main.py` — разбор аргументов и вывод результата;
- `tests/` — тесты вычислительной логики.


Для запуска программы сторонние библиотеки не нужны. Инструменты для проверки
устанавливаются командой `python -m pip install -r requirements-dev.txt`.

```bash
pytest
ruff check .
black --check .
mypy .
```
